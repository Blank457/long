# 云享 CloudShare · 参赛作品说明

> 基于 **华为云 OBS 对象存储 + FunctionGraph Serverless** 的智能文件协作分享平台
> 华为 ICT 大赛 / 云开发者大赛 参赛作品

## 一、作品概述

**云享 CloudShare** 是一款面向个人与团队的轻量级云端文件协作分享 Web 应用。用户拖拽文件即可一键上传至华为云 OBS，生成专属分享链接，支持**在线预览、提取码保护、有效期控制**，实现"一键上云、秒级分享"。

作品采用 **Serverless 架构**，后端零运维、按需付费，前端为纯静态网页，可托管于 OBS 静态网站，整体方案充分体现华为云"**对象存储 + 函数计算 + IAM 临时凭证**"的最佳实践。

## 二、核心亮点

| 亮点 | 说明 |
| --- | --- |
| **STS 临时凭证安全直传** | 前端不持有永久 AK/SK，通过 FunctionGraph 下发 IAM 临时凭证（STS）直传 OBS，最小权限、到期自动失效，杜绝密钥泄露风险 |
| **预签名 URL 上传/下载** | 后端函数按需生成预签名 URL，前端浏览器直接与 OBS 交互，文件流量不经函数，性能高、成本低 |
| **多类型在线预览** | 图片、视频、音频、PDF、文本/代码文件浏览器内直接预览，无需下载 |
| **提取码 + 有效期双保险** | 分享链接可设置 6 位提取码与 1 小时～永久有效期，过期自动失效 |
| **Serverless 零运维** | 全后端仅一个 FunctionGraph 函数，无服务器、无数据库，分享元数据轻量存储，部署成本极低 |
| **演示模式可独立运行** | 未配置云环境时自动进入 localStorage 演示模式，评委无需任何配置即可体验完整 UI 与交互流程 |

## 三、功能清单

- 📤 **文件上传**：多文件拖拽上传至 OBS，实时进度展示
- 📁 **文件管理**：列表查看、搜索、删除、刷新
- 👁 **在线预览**：图片/视频/音频/PDF/文本/代码 多类型预览
- 🔗 **生成分享**：提取码保护 + 有效期（1h/24h/7d/30d/永久）
- 🔗 **分享访问**：独立分享页，提取码校验、预览、下载
- ⚙️ **连接配置**：支持 OBS 直连（AK/SK）与 STS 函数两种接入方式
- 📊 **统计概览**：文件数、总容量、分享数实时统计

## 四、技术架构

```
┌──────────────────────────────────────────────┐
│              浏览器（前端静态网页）              │
│   index.html / share.html / preview.html      │
│   纯 HTML + CSS + JS，托管于 OBS 静态网站       │
└───────────────┬──────────────────────────────┘
                │ ① STS 临时凭证 / ② 预签名 URL
                ▼
┌──────────────────────────────────────────────┐
│        华为云 FunctionGraph（Serverless）       │
│           sts-token 函数（Node.js）             │
│   生成 STS 凭证 / 预签名 URL / 列对象 / 删除     │
└───────────────┬──────────────────────────────┘
                │ ③ SDK 调用
                ▼
┌──────────────────────────────────────────────┐
│            华为云 OBS 对象存储桶                │
│         （文件实际存储 + 静态网站托管）          │
└──────────────────────────────────────────────┘
```

**数据流**：
1. 前端向 FunctionGraph 请求 STS 临时凭证或预签名 URL
2. 浏览器持临时凭证 / 预签名 URL **直接与 OBS 交互**上传、下载
3. 文件流量不经过函数节点，函数仅做凭证签发，冷启动与计费极低

## 六、技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | 原生 HTML5 / CSS3 / JavaScript (ES6+)，无框架依赖 |
| 后端 | 华为云 FunctionGraph（Node.js 18） |
| 存储 | 华为云 OBS 对象存储 |
| 安全 | 华为云 IAM 临时访问密钥（STS）+ OBS 预签名 URL |
| SDK | @huaweicloud/hcs-sdk-obs、@huaweicloud/hcs-sdk-iam |
| 开发工具 | **华为云 CodeArts（码道）代码智能体** 辅助全程开发 |

## 七、与同类产品差异

| 维度 | 传统网盘 | 本作品 |
| --- | --- | --- |
| 后端 | 长驻服务器 + 数据库 | Serverless 函数，零运维 |
| 上传 | 经业务服务器中转 | 浏览器直传 OBS，无中转 |
| 密钥 | 前端持永久密钥或经服务端 | STS 临时凭证，到期失效 |
| 成本 | 固定服务器费用 | 按调用次数计费，闲时为零 |
| 部署 | 多组件编排 | 一个函数 + 一个桶，分钟级上线 |

## 八、演示模式说明

为便于评委在无华为云环境时直接体验，作品内置**演示模式**：
- 未配置 AK/SK 与 STS 函数时自动启用
- 文件元数据与分享数据存于浏览器 `localStorage`
- 小于 5MB 文件以 DataURL 形式存储，可真实预览
- 完整复现上传、列表、分享、提取码、预览、下载全流程

接入真实华为云仅需在「⚙️ 配置」中填入桶名、Endpoint 与 STS 函数地址，详见 `docs/部署指南.md`。
## 九、开发过程与工具

本作品全程使用 **华为云 CodeArts（码道）代码智能体** 辅助开发，体现"AI 原生研发"理念。

### 9.1 开发工具

[华为云 CodeArts](https://developer.huaweicloud.com/codeartsco.html) 是华为云推出的一站式云原生开发平台，内置代码智能体，支持从需求理解、架构设计、代码生成到验证交付的全流程 AI 辅助。本作品即由 CodeArts 代码智能体在对话式交互中完成：

- **需求澄清**：智能体通过多轮提问明确大赛类型、作品形态、主题方向与规模
- **架构设计**：智能体自主确定 Serverless 架构（OBS + FunctionGraph + STS）与三模式客户端封装
- **代码生成**：前端三页面、样式、JS 逻辑、后端函数、文档均由智能体一次生成
- **自验证**：智能体内置预览能力，生成后即时渲染网页验证 UI 与交互

### 9.2 开发流程

```
用户一句话需求
   ↓  CodeArts 智能体澄清提问（大赛类型/主题/规模）
明确方案：华为云 OBS 云存储协作平台
   ↓  智能体生成项目骨架 + 全部代码 + 部署文档
即时预览验证 → 交付可演示作品
```
