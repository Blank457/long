# 云享 CloudShare · 华为云部署指南

本指南将作品从「演示模式」切换到「真实华为云 OBS」运行环境。预计耗时 15～30 分钟。

## 前置条件

- 已注册华为云账号，并完成实名认证
- 已开通 **OBS 对象存储**、**FunctionGraph 函数工作流**、**IAM 统一身份认证**

## 第一步：创建 OBS 桶

1. 进入 [OBS 控制台](https://console.huaweicloud.com/obs/) → 「桶列表」→ 「创建桶」
2. 配置：
   - 桶名：`cloudshare-<你的标识>`（全局唯一，如 `cloudshare-demo2026`）
   - 区域：华北-北京四（cn-north-4）
   - 桶策略：私有
   - 默认存储类别：标准存储
   - **开启静态网站托管**（可选，用于托管前端）
3. 记录 **桶名** 与 **Endpoint**（如 `obs.cn-north-4.myhuaweicloud.com`）

## 第二步：创建 IAM 委托（用于 STS 临时凭证）

1. 进入 [IAM 控制台](https://console.huaweicloud.com/iam/) → 「委托」→ 「创建委托」
2. 配置：
   - 委托名：`cloudshare_obs_agency`
   - 委托的账号：当前账号
   - 拥有权限：新建自定义策略，授予该桶的 `obs:bucket:GetObject`、`obs:object:PutObject`、`obs:object:GetObject`、`obs:object:DeleteObject` 权限
3. 记录 **账号 ID（Domain ID）** 与 **项目 ID（Project ID）**（在「我的凭证」页查看）

## 第三步：部署 FunctionGraph 函数

1. 进入 [FunctionGraph 控制台](https://console.huaweicloud.com/functiongraph/) → 「函数」→ 「创建函数」
2. 选择 Node.js 18 运行时，函数名 `cloudshare-sts-token`
3. 上传代码：将 `serverless/sts-token/` 目录打包为 zip 后上传
   ```powershell
   Compress-Archive -Path .\serverless\sts-token\* -DestinationPath .\sts-token.zip
   ```
4. 配置环境变量：
   | 变量 | 值 |
   | --- | --- |
   | OBS_AK | 你的永久 AK（仅函数使用，不下发前端） |
   | OBS_SK | 你的永久 SK |
   | OBS_BUCKET | cloudshare-demo2026 |
   | OBS_ENDPOINT | obs.cn-north-4.myhuaweicloud.com |
   | IAM_DOMAIN | 第 2 步的 Domain ID |
   | IAM_PROJECT_ID | 第 2 步的 Project ID |
   | IAM_AGENCY | cloudshare_obs_agency |
   | REGION | cn-north-4 |
5. 创建 HTTP 触发器（APIG），记录触发器 URL，如：
   `https://<apig-endpoint>/sts-token`

## 第四步：配置前端连接

打开 `index.html`，点击右上角「⚙️ 配置」，填入：
- OBS 桶名：`cloudshare-demo2026`
- OBS Endpoint：`obs.cn-north-4.myhuaweicloud.com`
- STS 函数地址：`https://<apig-endpoint>/sts-token`
- AK / SK：**留空**（走 STS 临时凭证，更安全）

保存后状态变为「已连接 · STS」，即可真实上传、分享、预览。

## 第五步（可选）：托管前端到 OBS 静态网站

1. 将 `index.html`、`share.html`、`preview.html`、`css/`、`js/` 上传到 OBS 桶根目录
2. OBS 控制台 → 桶 → 「基础配置」→ 「静态网站托管」：
   - 默认首页：`index.html`
   - 默认出错页：`index.html`
3. 访问桶的静态网站域名即可使用，分享链接自动指向该域名

## 安全建议

- **切勿**将永久 AK/SK 写入前端代码或提交到仓库
- 生产环境强制走 STS 临时凭证，函数中可进一步限制 `duration_seconds` 与对象前缀权限
- 分享提取码与有效期在前端校验仅做体验控制；强安全场景可将分享元数据迁至 FunctionGraph + GaussDB，由函数校验

## 故障排查

| 现象 | 排查 |
| --- | --- |
| 上传 403 | 检查委托权限是否包含 PutObject，桶是否为私有且预签名 URL 正确 |
| STS 获取失败 | 检查 IAM_AGENCY、Domain ID、Project ID 是否一致 |
| 跨域错误 | 函数已返回 CORS 头；若经 APIG，需在 APIG 分组开启 CORS |
| 预览空白 | 私有桶需通过预签名 URL 访问；演示模式下仅 <5MB 文件可预览 |
